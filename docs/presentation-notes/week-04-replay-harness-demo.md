# Presentation Notes — Historical WhatsApp Replay Harness (Week 04)

## 1. What we can show in the demo
- One command replays real historical customer conversations through today's agent.
- A polished, filterable HTML report: for each turn, the **exact** customer message,
  the **current agent's new reply**, and the **old staff reply** side-by-side.
- Real backend at work: pricing lookups, draft orders, workflow state, cost per turn.

## 2. Suggested demo flow
1. `python -m replay_harness dry-run --all` → shows 470 conversations, ~9,800 turns,
   estimated cost — all with zero LLM calls.
2. `python -m replay_harness run --conversation "<chat>"` → replays one chat live.
3. Open `replay_report.html`, filter to a complaint, and show the divergence:
   the old staff asked for location + price; the current agent asks for the order
   reference and a photo (current complaint policy). The old reply is shown for
   comparison but was never given to the agent.

## 3. Screenshots needed

- A conversation thread with the three-way bubbles (customer / current agent /

## 4. Talking points
- "We replayed hundreds of real conversations against the current agent without
  typing a single message and without messaging any real customer."
- "Every reply is generated by the real production pipeline — same model, prompts,
  pricing catalogue, discount rules, pickup engine, memory, and safety policies."
- "The only thing we swapped is the part that actually sends the WhatsApp message."

## 5. Technical explanation in simple language
The historical messages are read from the WhatsApp export, the customer's exact
words are fed to the live agent one turn at a time, and we capture what the agent
would have replied. The agent thinks it is talking to a test number that can't
route anywhere, and the outbound sender is a recorder, not a transmitter.

## 6. Business value
- Regression-test the agent against real customer language at scale.
- See exactly where today's policies differ from past staff behaviour.
- Estimate cost before spending, and cap spend with a hard ceiling.
- Reusable to compare models (Haiku vs Sonnet) or prompt versions later.

## 7. Before vs after
- Before: manual, one-message-at-a-time testing from a single allow-listed phone.
- After: 470 conversations replayed automatically with downloadable evidence.

## 8. Risks / caveats to mention honestly
- Live model calls cost real money; the full archive is ~$87 on Sonnet 5, above the
  $70 checkpoint, so the full run needs sign-off.
- Image-without-caption turns currently produce no reply (matches production).
- The automated evaluator covers a strong subset of rules; deeper price-correctness
  checks are future work (not silently passed — surfaced as limitations).

## 9. What is coming next
Full-archive run on approval, triage of critical/failed conversations, and feeding
systemic findings back into agent tuning. Optional: an internal "Replay Testing"
dashboard page over the same data.
